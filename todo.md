## ⚙️ Первичная настройка окружения (С нуля)
- [x] Открыть встроенный терминал в VS Code (`Ctrl + \``)
- [ ] Разрешить выполнение скриптов в Windows (Если выскочит ошибка активации!)
  * *В терминале VS Code выполнить:* `Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope Process`
- [x] Создать изолированное виртуальное окружение `.venv`
  * *Команда:* `python -m venv .venv`
- [x] Активировать виртуальное окружение в терминале
  * *Для PowerShell:* `.venv\Scripts\Activate.bat`
- [x] Обновить установщик пакетов `pip`
  * *Команда:* `python -m pip install --upgrade pip`
- [x] Установить все библиотеки из файла зависимостей
  * *Команда:* `pip install -r requirements.txt`

## 🔄 Как запустить КОПИЮ папки (Новый проект на этом шаблоне)
Если вы скопировали эту папку для другого проекта, вам нужно выполнить всего 3 шага:
- [ ] 1. Открыть скопированную папку в VS Code.
- [ ] 2. Открыть новый терминал и **активировать** уже существующее окружение:
  * *Команда:* `.venv\Scripts\Activate.ps1`
- [ ] 3. В файле `.ipynb` заново выбрать ядро (Kernel) -> указать на `.venv` этой новой папки.

## 💻 Перенос проекта на другой компьютер (Windows)
⚠️ **ВАЖНО:** Никогда не копируйте папку `.venv` на другой компьютер! Она привязана к путям текущей системы и работать не будет.
- [ ] При переносе скопировать только файлы: `requirements.txt`, `project.ipynb` и `TODO.md`.
- [ ] На новом компьютере открыть папку в VS Code и выполнить блок задач **«Первичная настройка окружения (С нуля)»**.

## 🍏🐧 Справка: Эквиваленты команд для macOS и Linux
Если проект потребуется запустить на Mac или Linux, используйте эти команды вместо Windows-версий:
* **Создание окружения:** `python3 -m venv .venv`
* **Активация окружения:** `source .venv/bin/activate`
* **Обновление pip:** `python3 -m pip install --upgrade pip`
* **Установка библиотек:** `pip install -r requirements.txt`
